DIGITAL PRINT

Bienvenue sur DIGITAL PRINT !

Présentation

DIGITAL PRINT est une plateforme commerciale dédiée à la vente de téléphones et de produits numériques.

Fonctionnalités

- Catalogue de téléphones avec photos et prix.
- Prix en dollars américains (USD) et francs congolais (CDF).
- Gestion du stock.
- Inscription et connexion des clients.
- Gestion des commandes.
- Historique des achats.
- Espace administrateur.

Technologies utilisées

- Node.js
- Express.js
- SQLite
- HTML
- CSS
- JavaScript

Installation

Installer les dépendances :

npm install

Démarrer le serveur :

npm start
